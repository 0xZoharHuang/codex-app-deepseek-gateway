# 本地 runtime 验收合同

固定 Windows 10 x64 19045、签名 App 26.1023.6621.0、原生 0.165.0-alpha.1.2 和上游提交 `720fec862a608ae1e5878d1eecb04fb93192e93c`。0.2.0 使用 P19 锁与六程序包。P7 是 0.1.0 的历史组合，P9 是保留的来源提案。各项实行条件、观察和原始失败均按版本单列，见[资格索引](qualification-status.md)。本页定义验收合同。

| 能力族 | 验收要点与状态判定 |
| --- | --- |
| 来源与隔离 | 官方签名/版本、实际 PID/出生时间/身份/映像 SHA；独立 home、前端、安装、凭据项与服务；不接管其他用户/App/CDS。配置声明不能代实际加载。 |
| 模型与协议 | 固定模型、明确辅助别名及提供方优先级；Responses/SSE 的完成、失败、截流；custom/function/namespace、发现、Code Mode、完整调用/结果历史与结构化输出。无法表达的语义明确失败，不丢字段或改成成功。 |
| 工具与扩展 | 原生终端、文件修改、diff/Undo、技能、插件、MCP/AppTools；实际参数、调用 ID、返回、上下文与结果归属。发现工具不等于执行；queued 不等于展示成功。 |
| 权限与控制 | 文件/网络真实允许与拒绝、人工批准/拒绝、Guardian Allow/Deny、取消和后台选择性终止。不得切 full access/关闭审批缩小范围；宿主权限 fixture 与原生沙箱执行分开。 |
| 状态与协作 | 主/子/孙、消息归属、等待、跟进、打断、各版本实际生命周期和同 UUID 冷恢复；goal、Steer、客户端 queue；SDK 门为 false 的 server queue 不能冒作正向执行。 |
| 上下文 | 记忆提取/整合/新会话读取、自动/手动压缩、完整历史前后缀、冷继续。getter 或空数据库不能代实际形成；保留中间失败。 |
| 存储兼容 | 原 SQL 的已知 LF/CRLF 严格匹配、旧账本/用户行/附件/rollout 前缀保留，未知/dirty 仍拒绝；fresh 官方互读与 legacy profile 维护分别核验，不伪造 lazy store。 |
| 工作树 | 创建/挂接、相对读/cwd/最小权限、归档/快照/恢复/登记、原工作目录保护；不手改路径/ref/opaque 附件绕过原版 bug。相同错误的 stock 对照是负向归类，不是恢复成功。 |
| 网页与数据 | 真 search/open/find/click、session/ref/source grant 和旧引用恢复；非空 recency/location 的完整映射与实际 HTTP/hash；时间和天气分路径。图片 metadata 不代像素/缓存/显示；不把外部排序质量与本地接线混为一谈。 |
| 媒体 | 本次 PDF HTTP/raw→renderer→PNG bytes/dimensions→原生返回→App 实际预览；view_image typed pixels→适配/传输/provider；普通用户可读模型输出。文本化 dataURL 不算 typed 图，旧截图不代当前。 |
| 实际任务 | 由 App 中的 DeepSeek 完成多文件工程与带网页/MCP/子智能体的任务；独立检查、失败修复/中断续跑。controller 只准备观察验收，不替模型写业务结果。 |
| 故障与副作用 | 413/429/503、认证失效/刷新、半截流/断网/网关丢失、同端口恢复、取消；失败不能伪装完成或重复已有副作用。未知启动回读同一次状态，不重投。 |
| 安装与交付 | 正常 install/activate/prepare/bind/configure/start/status、升级、回滚、卸载，固定来源和外部校验索引；最后才有界整理自有 Windows 材料。 |

公开 0.1.0 / P7 的软件、原生构建、实际加载/会话保留、fresh 互读、网页工程及 R27 媒体已按分层证据关闭；这些历史结果不关闭 P19 的受影响路径。先核验新组合实际加载与 fresh readonly 工具路径，再按原影响分析完成 413/96 图/压缩前后缀、取消副作用、同 UUID 冷恢复、图片 lease、辅助调用及真实 App 任务；无关旧项只在组件、配置与路径相等时承接。首轮文本误用、扩大 NoPattern、错误夹具权限拒绝仍保留；正确新夹具的宿主读取正向不改写旧文件，也不代复杂任务。最终发行、字节读回、环境整理与当时使用额度复核仍是单独交付门。1,747 软件主节点、19 subtests、metadata、focus、native unit 和实际 App 行为分别记账，重叠节点不相加。

原 37 项矩阵的 R17、R35、R36 是条件未提供，不能记作正向通过；R25 是同版本原版 `restore_worktree` 的负向对照，不能记作恢复成功。继续使用这份既有合同，不以新增大矩阵代替实际关闭缺口。

模型推理/视觉质量、OpenAI 私有账户/typed 数据权益和第三方排序/数据精度单列。金融与体育 feed 未接入，不计正向；其他本地/web API 仍按各自合同验收。Win10 不外推 Win11 MXC/安全桌面；IAB/计算机等需按实际平台/有效门记录，不仅凭名称作通过或任意排除。

组件承接必须绑定原实测版本、源码、配置与输入差异；CLI、GUI 操作受理、实际执行、模型结果和整任务成功是不同层。公开 hash 是去敏索引，不是假称外部认证。原始错误、observer 修正、模型误用和未执行条件都保留。
